## 🧰 Tools I Built and Use

These are the projects I use myself. They run on my own machine and use a local AI model.

- 🎯 [**job-scout**](https://github.com/oo0speed0oo/job-scout) - A private job-search dashboard. It searches with SearXNG, reads each page with a local Ollama model, and sorts jobs into Yes, Maybe and No. Profiles, rules for remote work, days off and hours, a live log and a standalone HTML export. It never applies or logs in for me. *(Python standard library only, single-file HTML interface)*
- 🔎 [**search-helper**](https://github.com/oo0speed0oo/search-helper) - A local AI research helper. I type what I want to find out, review the generated search queries, and it searches, reads pages, rates each one, and writes an action plan with sources. Saves HTML, CSV and plain-text reports and has offline tests. *(Python standard library only, Ollama, SearXNG)*
- 🎬 [**reel2txt**](https://github.com/oo0speed0oo/reel2txt) - Paste a video, post, web page, PDF or Reddit link. My Linux box downloads it, transcribes the speech (English and Japanese), reads on-screen text with OCR, summarizes it and files it into my projects. Private, runs over Tailscale as a systemd service. *(Python, yt-dlp, faster-whisper, ffmpeg, Playwright, Ollama)*
- 🗂️ [**web-archive-tools**](https://github.com/oo0speed0oo/web-archive-tools) - A web scraper and OCR toolkit for archiving articles and extracting text from images and PDFs. It supports Japanese and English OCR and can resume where it stopped. *(Python, Tesseract)*
